# 接口接入说明

当前工程使用 `SampleData.swift` 演示完整交互，接入现有服务端时建议保持以下边界：

1. iOS 客户端只请求你的服务端代理，不在 App 中保存模型 API Key。
2. 每日推荐接口返回稳定的 `recipeID`，保证同一天结果一致。
3. 完成菜谱时上传结构化事件：菜谱、菜系、标签、时间、是否随机推荐、是否给别人做、照片等。
4. 称号判定可先在本地反馈，再由服务端幂等确认；服务端以事件流水为最终事实来源。
5. 玄学文案明确标注娱乐性质；过敏、忌口、食材安全和烹饪步骤以真实规则优先。
6. 点赞、分享、连续不点外卖等跨设备条件应由账号后端统计。
