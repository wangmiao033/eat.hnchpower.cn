# 美味助手 · 玄学厨房产品规格

## 定位
玄学厨房不是只输出运势文案的占卜页，而是“今天吃什么”的游戏化决策器。

```text
选择玩法 → 3–8 秒互动仪式 → 得到真实菜谱 → 接受天命开始做饭 → 称号成长
```

## 一级导航
```text
今日｜饭局｜玄学｜菜谱｜我的
```
玄学独立成一级入口，紧挨饭局。AI 创作保留在今日页快捷入口和菜谱页工具区，避免底栏超过五项。

## 六种玩法
1. **今日食运**：星座、生肖和日期生成当天的幸运味型、食材和菜谱。
2. **心情开锅**：按开心、疲惫、焦虑、想家、兴奋、平静匹配操作负担和味型。
3. **塔罗菜牌**：抽取料理原型牌，翻牌后落到具体菜谱。
4. **幸运数字**：1–99 稳定映射菜系、味型和候选菜。
5. **缘分合锅**：计算两人的口味交集，并联动饭局分工。
6. **五味灵签**：摇动手机抽酸、甜、苦、辣、咸鲜。

## 结果必须包含
- 菜名、时间、难度
- 幸运味型和幸运食材
- 娱乐性质的玄学解释
- 三步料理挑战
- “接受天命 · 开始做饭”
- “不认命 · 再算一次”
- “去饭局决定谁做饭、谁洗碗”

## 成长联动
首次通过玄学厨房选出菜谱，解锁隐藏称号 **天机开锅**。完成菜谱后才累计完成类称号，单纯反复抽取不能刷成长值。

## 视觉与动效
- 深梅色、柔金、暖白，避免廉价霓虹紫。
- 抽牌约 1.2 秒；摇签约 0.9 秒；结果用底部 Sheet 揭晓。
- 开始做饭后停止玄学背景动画。
- 支持“减弱动态效果”。

## 内容边界
玄学仅作娱乐。过敏、忌口、营养目标、食材安全和烹饪步骤始终以真实信息优先。

## 建议埋点
`mystic_home_view`、`mystic_mode_select`、`mystic_cast_start`、`mystic_cast_result`、`mystic_recipe_accept`、`mystic_to_party`、`mystic_recipe_complete`、`mystic_hidden_title_unlock`。

核心漏斗不是“占卜次数”，而是：
```text
进入 → 启动互动 → 查看结果 → 接受菜谱 → 开始烹饪 → 完成菜谱
```
