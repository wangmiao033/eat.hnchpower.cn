# 美味助手完整功能清单

本包将此前各轮设计合并为一个版本，当前包含：

## 一级结构

- **今日**：每日一菜、换一道、今晚灵感、AI 菜谱创作快捷入口。
- **饭局**：一体式真六面 D6 食谱骰子、谁做饭/谁洗碗、多人的主厨/洗碗/帮厨/采购分工。
- **玄学**：今日食运、心情开锅、塔罗菜牌、幸运数字、缘分合锅、五味灵签。
- **菜谱**：收藏、做过、菜单、AI 菜谱创作、一桌好菜、酱料助手。
- **我的**：主线等级、隐藏称号、展示称号、偏好、忌口、提醒与隐私设置。

## 菜谱闭环

每日推荐或游戏选菜 → 菜谱详情 → 食材勾选 → 分步烹饪模式 → 完成记录 → 称号升级/隐藏称号判断。

## 骰子规格

- 一体式圆角实体 D6。
- 六个真实面，点阵布局固定。
- 相对面为 1–6、2–5、3–4，相对面点数和为 7。
- 支持拖动观察、点击投掷、翻滚、落地回弹、阴影和触觉反馈。
- SceneKit 使用 `Assets.scnassets/TrueD6.obj`；同时附原始 `true-d6.glb`。

## 称号系统

- 主线称号：25 个。
- 隐藏称号：75 个，其中包含新增的「天机开锅」。
- 完整 JSON 数据与通用规则解析器已放入 App 资源。

## 交付形态

- 一个整合后的交互原型：`WebPrototype/index.html`。
- 一个 Xcode 工程：`iOS/MeiweiAssistant.xcodeproj`。
- XcodeGen 备用配置：`iOS/project.yml`。
- 完整 SwiftUI 源码、App Icon、真 D6 模型、称号数据、设计文档和预览图。
