# 就美味助手微信小程序

这是从当前 Web 项目拆出的微信小程序 MVP，先实现本地推荐、偏好筛选、摇一摇推荐和收藏。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本目录：`miniprogram`。
4. AppID 已写入 `project.config.json`。

## 安全边界

- `AppID` 可以放在小程序项目配置里。
- `AppSecret` 不能放在小程序客户端，也不能提交到 Git。
- AI 服务的 API Key 也不能放在小程序客户端。
- 后续接 AI 时，应新增服务端代理接口，例如 `POST /api/recipes/generate`，由服务端读取环境变量并调用 AI。

## 下一步建议

- 增加服务端代理接口，统一处理 AI 菜谱生成。
- 在微信公众平台配置服务端 HTTPS 域名为 request 合法域名。
- 把现有 Web 项目的菜系、食材和提示词逐步迁移为小程序可复用的数据模块。
